Технологический стек
Почему именно эти технологии
🐍

Python 3 + Django

  • Читаемый и простой язык
  • Батарейки в комплекте: admin, ORM, auth
  • Быстрая разработка
🔌

Django REST Framework

  • Сериализаторы и валидация
  • Готовые generics-вьюхи
  • Права доступа (permissions)
  • Встроенная пагинация и фильтры
🔐

JWT (simplejwt)

  • Токен-аутентификация
  • Access + Refresh токены
  • Чёрный список при выходе
📖

Swagger + тесты

  • Автодокументация API
  • 23 теста покрывают сценарии
  • SQLite для разработки
