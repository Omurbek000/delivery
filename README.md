# delivery
Система предназначена для автоматизации процесса приёма и обработки заказов **одного конкретного ресторана** (не агрегатор нескольких заведений). Пользователями системы являются:  1. **Клиент** — просматривает меню, оформляет заказ, отслеживает его статус. 2. **Администратор/сотрудник ресторана** — управляет меню, обрабатывает заказы, меняет их статус.
